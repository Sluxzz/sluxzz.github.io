# Site-repetitor
# Сайт-визитка репетитора по математике

Сайт создан в рамках учебного проекта по управлению IT-проектами.  
Цель — получить рабочий сайт-визитку для привлечения учеников.

## Технологии
- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- GitHub Pages (хостинг)

## Локальный запуск

1. Скачайте репозиторий: https://github.com/Sluxzz/sluxzz.github.io 
2. Откройте папку с проектом
3. Запустите `index.html` в браузере (или используйте Live Server в VS Code)

## Как обновлять контент

### Изменить цены
Файл `index.html`, блок с классом `price-list`. Найти нужную цену и заменить.

### Добавить отзыв
Скопировать блок `.review` и вставить перед закрывающим `</div>` контейнера.

### Изменить предметы
Блок `.subjects` — менять текст внутри `<span class="subject">`.
